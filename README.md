Entry for the [One Line, One Chill](https://make.fun/bounty/u-azazex-one-line-one-chill-6d4d5488) bounty on [make.fun](https://make.fun/bounty/u-azazex-one-line-one-chill-6d4d5488): a program that writes the single scariest sentence it can — one line of horror, under 200 characters — to `/output/entry.txt`.

## The entry

> My smart speaker keeps replaying my breathing from the empty bedroom — in perfect time with the breathing behind me.

(116 characters, one sentence, one line.)

## Run it

Requires Node 22+:

```sh
node main.ts
cat /output/entry.txt
```
